WATCH DOG (가칭)

노령 반려동물 방문 돌봄 · 제천 시범 준비 중

투약부터 보행까지,노령 반려동물 필수 케어 전문 매칭 플랫폼

필요한 케어를 해 본 사람만 보여 주고, 예약 전에 총액과 케어 계획을 확정합니다. 오른쪽 폰의 버튼을 직접 눌러 보세요.

        2

        '해 봤다'를 믿을 수 없어요

        "노견 가능"만으로는 알 수 없습니다.

        3

        총액은 직전에야 알아요

        추가 항목 때문에 비교가 어렵습니다.

        가상 예시: 확정까지 17일, 문의 15건. 실제 측정값이 아닙니다.

        2 해결

        케어 계획서 기반 매칭, 하나만 합니다

        1

        업무별 경험 확인

        식사·배변·보행 보조, 투약마다 해 본 경험을 표시합니다.

        2

        예약 전 총액 확정

        방문비, 이동비, 수수료를 합친 한 장 견적을 먼저 봅니다.

        3

        계획서와 수행 기록

        정한 케어를 문서로 남기고 방문마다 확인합니다.

        이용 순서 케어 입력 5분 → 해 본 사람 확인 → 한 장 견적 → 사전 만남·계획서 확정

        3 가격과 혜택

        사전예약 혜택

        우선 매칭첫 시범에서 요청을 먼저 매칭합니다.
