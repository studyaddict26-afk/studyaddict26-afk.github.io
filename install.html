홀로를 앱처럼 설치하세요

홈 화면에 아이콘이 생겨서, 주소를 치지 않고 한 번에 열 수 있어요. 따로 받는 파일은 없고 무료예요.

이미 설치되어 있어요

지금 이 화면이 설치된 홀로예요. 아래 버튼으로 홀로를 열 수 있어요.

홀로 열기

버튼 한 번이면 끝나요

아래 버튼을 누르고, 나타나는 창에서 설치를 눌러 주세요.

설치됐어요

홈 화면(또는 바탕화면·시작 메뉴)에서 홀로 아이콘을 찾아 열어 주세요.

홀로 열기

다른 브라우저에서 열어 주세요

지금 보고 있는 화면은 카카오톡 같은 앱 안의 간이 브라우저라서 설치할 수 없어요. 아래 버튼으로 주소를 복사한 뒤, 브라우저에 붙여 넣어 열어 주세요.

아이패드·아이폰: 이렇게 하세요

  1. 화면 위쪽 또는 아래쪽의 공유 버튼 (네모에서 화살표가 위로 나가는 모양)을 누르세요.
  2. 메뉴에서 홈 화면에 추가를 고르세요. 안 보이면 메뉴를 위로 밀어 올려 보세요.
  3. 이름이 홀로로 나오면 오른쪽 위 추가를 누르세요.

꼭 사파리에서 해야 해요. 크롬이나 다른 앱에서는 이 메뉴가 없어요.

이렇게 설치하세요

  1. 브라우저 주소창 오른쪽 끝에 설치 아이콘(모니터에 아래 화살표 모양)이 보이면 누르세요.
  2. 안 보이면 브라우저 메뉴(점 세 개)에서 앱 설치 또는 홀로 설치를 찾아 누르세요.
  3. 나타나는 창에서 설치를 누르세요.

메뉴에 설치 항목이 없다면 크롬, 엣지, 웨일에서 다시 열어 보세요. 맥의 사파리는 위쪽 메뉴의 파일 → Dock에 추가를 누르세요.

다른 기기에서는

아이패드·아이폰 — 사파리에서 열고, 공유 버튼 → 홈 화면에 추가 → 추가.

노트북(크롬·엣지·웨일) — 주소창 오른쪽 끝의 설치 아이콘, 또는 메뉴 → 앱 설치.

안드로이드 — 크롬에서 열고, 이 페이지의 홀로 설치하기 버튼 또는 메뉴(점 세 개) → 홈 화면에 추가.

설치하면 로그인은 앱에서 한 번 더 해야 할 수 있어요. 막히면 독서실 선생님께 문의해 주세요.
