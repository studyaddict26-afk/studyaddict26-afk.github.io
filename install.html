브라우저에서 열어 주세요

이미 설치되어 있어요

지금 보는 화면이 설치된 HOLO예요.

HOLO 열기
  1. 주소창 오른쪽 끝에 설치 아이콘(모니터에 아래 화살표 모양)이 보이면 누르세요.
  2. 안 보이면 브라우저 메뉴(점 세 개)에서 앱 설치 또는 HOLO 설치를 누르세요.
  3. 나타나는 창에서 설치를 누르세요.

크롬, 엣지, 웨일에서 할 수 있어요. 맥의 사파리는 위쪽 메뉴의 파일 → Dock에 추가를 누르세요.

  1. 사파리에서 이 페이지를 열고, 화면 위쪽의 공유 버튼 (네모에서 화살표가 위로 나가는 모양)을 누르세요.
  2. 메뉴에서 홈 화면에 추가를 고르세요. 안 보이면 메뉴를 위로 밀어 올려 보세요.
  3. 이름이 홀로로 나오면 오른쪽 위 추가를 누르세요.

사파리가 가장 확실해요. 크롬 같은 다른 브라우저는 공유 메뉴에 홈 화면에 추가가 있을 때만 돼요. iPhone도 같은 방법이에요. (애플 정책상 iPad·iPhone은 버튼 한 번으로 설치할 수 없어요.)

  1. 크롬(또는 삼성 인터넷)에서 이 페이지를 열고, 메뉴(점 세 개 또는 줄 세 개)를 누르세요.
  2. 홈 화면에 추가 또는 앱 설치를 누르세요.
  3. 나타나는 창에서 설치(또는 추가)를 누르세요.

HOLO로 이동설치 후에는 앱에서 한 번 더 로그인해야 할 수 있어요.
